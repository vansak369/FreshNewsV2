# 📰 Fresh News

Fresh News is a web-based **social news platform** where users can read, browse, and share news. Users can also create their own news posts with images.

## ✨ Features

* 👤 User registration & login
* 📰 Browse and read news
* 📂 News categories
* ✍️ Create and publish news
* 🖼️ Upload images for posts
* 🌐 User-generated content

## 🛠️ Technologies

* **Frontend:** React.js, Vite, HTML, CSS, JavaScript
* **Backend:** Firebase
* **Authentication:** Firebase Authentication
* **Database:** Cloud Firestore
* **Storage:** Firebase Storage

## 🚀 Run the Project

```bash
npm install
npm run dev
```

Then open the local URL provided by Vite.

## 🎯 Project Scope

Fresh News focuses on **news browsing, user-generated news posting, authentication, image uploading, and basic social interaction**.

## ⚠️ Limitations

This is an **academic project**, so it does not include advanced features such as large-scale recommendation systems, professional news verification, or advanced content moderation.
